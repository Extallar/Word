# 편입영어 기출 단어장

한국공학대학교 편입영어 2022–2026학년도 기출(시험지·해설 PDF와 기출 분석 엑셀)로 만든 단어 공부 사이트입니다.

## 기능
- **오늘**: 하루 루틴(복습 카드 → 새 단어 → 오늘 단어 퀴즈 → 주말 실전 기출). 간격 반복(몰라요: 내일, 알아요: 1·3·7·14·30일 간격), 연속 학습일, 7일 복습 예보, 하루 새 단어 수·등급 설정. 퀴즈·기출에서 틀린 단어는 다음 날 복습에 자동 추가. 시험일 D-day, 목표 범위, 새 단어 마감(시험 14일 전), 하루 권장 개수와 예상 완료일
- **단어장**: 5개년 시험지 원문에 나온 단어 3,161개(표제어 기준). 등급(직접 출제 / 반복 학술 / 심화 / 일반 / 기본 / 고유명사), 학년도 필터, 검색, 동의어, 기출 예문과 문항 번호, 뜻 가리기, 외운 단어 표시, 발음
- **카드 / 퀴즈**: 등급별 묶음으로 플래시카드, 뜻·동의어 4지선다
- **실전 기출**: 연도별 40문항을 지문·배점까지 원문 그대로. 답을 고른 뒤에만 정답과 공식 해설 표시, 점수 집계
- **기출 1~8번**: 원문 문장(밑줄·빈칸 포함)으로 어휘 문제, 풀이 후 공식 해설과 보기별 뜻·동의어
- **문맥 빈칸**: 17~25번 지문 원문, 풀이 후 공식 해설과 판단 근거
- **풀이법 / 오답노트**
- 상단의 **내 자료로 공부하기** 버튼을 누르면 따로 만든 공부 사이트(`study/`)로 이동합니다.

학습 기록은 브라우저 localStorage에 저장됩니다.

## 단어 등급 기준 (5개년)
| 등급 | 기준 |
|---|---|
| 직접 출제 | 1~8번 표적어·정답·보기, 17~25번 한 단어 정답 (여러 단어 표현은 구 그대로) |
| 반복 학술 | 2개년 이상 출현, 일상 빈도(wordfreq Zipf) 5.0 미만 |
| 심화 | 1개년만 출현, Zipf 3.6 미만 |
| 일반 | 1개년만 출현, Zipf 3.6 이상 5.0 미만 |
| 기본 | Zipf 5.0 이상 또는 문제 지시문 단어 |
| 고유명사 | 인명·지명 등 |

## 실행
빌드 없이 `index.html`을 브라우저로 열면 됩니다.

## 데이터 다시 만들기
```bash
pip install openpyxl lemminflect wordfreq   # pdftotext(poppler-utils) 필요
# 1) 시험지 원문: 폴더에 2022_q.pdf(문제), 2022_a.pdf(해설) … 2026_a.pdf
python3 tools/parse_exam.py <PDF폴더> data/exam.js
# 2) 단어 데이터: 원문을 표제어 단위로 다시 세고 엑셀 뜻·분석과 합침
python3 tools/extract.py <기출분석.xlsx> data/words.js
```
- `tools/regroup.py`: 표제어 묶기(활용형만 묶고 파생어는 분리), 예외는 `OVERRIDE`
- `data/meanings/*.tsv`: 엑셀에 없는 뜻(단어<TAB>뜻). `z_context.tsv`는 기출 문맥에 맞춰 고친 뜻
- `data/synonyms/*.tsv`: 동의어(쉼표 구분, `-`는 없음). 기출 1~5번 정답 쌍이 먼저 표시됨
- `python3 tools/build_single.py`: 한 장짜리 `dist/single.html`

## 자료 학습 노트 (`study/`)
단어장과 별개인 공부 사이트입니다. `study/index.html`을 열면 됩니다(빌드 없음). 태블릿·노트북 화면 기준으로 만들었습니다.

- 교재·필기·지문을 붙여 넣거나 파일(텍스트·PDF·이미지)로 넣으면 한 줄 요약, 핵심 정리, 정리 노트, 용어 카드, 연습 문제(객관식·OX·빈칸·단답)를 만듭니다.
- 문제마다 해설과 원문 근거를 보여 주고, 자료별 보관함에 풀이 기록을 저장해 틀린 문제만 다시 풀 수 있습니다.
- **Claude × GPT 상의 모드** (두 API 키를 모두 넣었을 때)
  - 만들기: 작성자(Claude 또는 GPT)가 초안 → 다른 AI가 원문과 대조해 검토(문제별 좋음/수정/교체) → 작성자가 의견을 따져 반영하거나, 반영하지 않은 이유를 남기고 수정. 검토는 1~2번.
  - 단답 채점: 두 AI가 따로 채점하고, 의견이 다르면 서로의 채점을 보고 다시 판단. 끝까지 갈리면 학생이 직접 판단.
  - 자료마다 **상의 기록** 탭에서 두 AI가 주고받은 내용을 볼 수 있습니다.
- 키가 하나면 그 AI 혼자 만들고, 키가 없으면 **기본 모드**(중요 문장 추출 요약 + 핵심어 빈칸·OX 문제)로 만듭니다.
- 요청은 브라우저에서 각 회사 API로 바로 갑니다(Anthropic SDK 1.7.0, OpenAI SDK 7.50.0을 jsDelivr에서 불러옴). 키와 보관함은 이 브라우저의 localStorage에만 저장되고, 쓴 만큼 각 API 요금이 나옵니다.
- 파일: `local.js`(기본 모드), `ai.js`(Claude·GPT 호출과 상의 절차), `app.js`(화면), `style.css`
