# 편입영어 기출 단어장

한국공학대학교 편입영어 2022–2026학년도 기출(시험지·해설 PDF와 기출 분석 엑셀)로 만든 단어 공부 사이트입니다.

## 기능
- **오늘**: 하루 루틴(복습 카드 → 새 단어 → 오늘 단어 퀴즈 → 주말 실전 기출). 간격 반복(몰라요: 내일, 알아요: 1·3·7·14·30일 간격), 연속 학습일, 7일 복습 예보, 하루 새 단어 수·등급 설정. 퀴즈·기출에서 틀린 단어는 다음 날 복습에 자동 추가. 시험일 D-day, 목표 범위, 새 단어 마감(시험 14일 전), 하루 권장 개수와 예상 완료일
- **단어장**: 5개년 시험지 원문에 나온 단어 3,161개(표제어 기준). 등급(직접 출제 / 반복 학술 / 심화 / 일반 / 기본 / 고유명사), 학년도 필터, 검색, 동의어, 기출 예문과 문항 번호, 뜻 가리기, 외운 단어 표시, 발음
- **카드 / 퀴즈**: 등급별 묶음으로 플래시카드, 뜻·동의어 4지선다
- **실전 기출**: 연도별 40문항을 지문·배점까지 원문 그대로. 답을 고른 뒤에만 정답과 공식 해설 표시, 점수 집계
- **기출 1~8번**: 원문 문장(밑줄·빈칸 포함)으로 어휘 문제, 풀이 후 공식 해설과 보기별 뜻·동의어
- **문맥 빈칸**: 17~25번 지문 원문, 풀이 후 공식 해설과 판단 근거
- **풀이법 / 오답노트**
- 상단의 **내 자료로 공부하기** 버튼을 누르면 따로 만든 공부 사이트(`study/`)로 이동합니다.

학습 기록은 브라우저 localStorage에 저장됩니다.

## 단어 등급 기준 (5개년)
| 등급 | 기준 |
|---|---|
| 직접 출제 | 1~8번 표적어·정답·보기, 17~25번 한 단어 정답 (여러 단어 표현은 구 그대로) |
| 반복 학술 | 2개년 이상 출현, 일상 빈도(wordfreq Zipf) 5.0 미만 |
| 심화 | 1개년만 출현, Zipf 3.6 미만 |
| 일반 | 1개년만 출현, Zipf 3.6 이상 5.0 미만 |
| 기본 | Zipf 5.0 이상 또는 문제 지시문 단어 |
| 고유명사 | 인명·지명 등 |

## 실행
빌드 없이 `index.html`을 브라우저로 열면 됩니다.

## 데이터 다시 만들기
```bash
pip install openpyxl lemminflect wordfreq   # pdftotext(poppler-utils) 필요
# 1) 시험지 원문: 폴더에 2022_q.pdf(문제), 2022_a.pdf(해설) … 2026_a.pdf
python3 tools/parse_exam.py <PDF폴더> data/exam.js
# 2) 단어 데이터: 원문을 표제어 단위로 다시 세고 엑셀 뜻·분석과 합침
python3 tools/extract.py <기출분석.xlsx> data/words.js
```
- `tools/regroup.py`: 표제어 묶기(활용형만 묶고 파생어는 분리), 예외는 `OVERRIDE`
- `data/meanings/*.tsv`: 엑셀에 없는 뜻(단어<TAB>뜻). `z_context.tsv`는 기출 문맥에 맞춰 고친 뜻
- `data/synonyms/*.tsv`: 동의어(쉼표 구분, `-`는 없음). 기출 1~5번 정답 쌍이 먼저 표시됨
- `python3 tools/build_single.py`: 한 장짜리 `dist/single.html`

## 자료 학습 노트 (`study/`)
단어장과 별개인 공부 사이트입니다. 태블릿·노트북 화면 기준으로 만들었습니다.

- 교재·강의 PDF·필기·지문을 넣으면 한 줄 요약, 핵심 정리, 정리 노트, 용어 카드, 연습 문제(객관식·OX·빈칸·단답)를 만듭니다. 문제마다 해설과 원문 근거(쪽 번호)를 보여 주고, 자료별 보관함에 풀이 기록을 저장해 틀린 문제만 다시 풀 수 있습니다.
- **PDF**: 브라우저에서 바로 글자를 읽습니다(pdf.js 3.11.174, cdnjs). 쪽 범위를 고를 수 있고, 뽑은 글자에 `[p.N]` 쪽 표시가 붙습니다. 스캔한 그림 PDF는 페이지를 사진으로 넣어 주세요.
- **AI 모드 (Claude)**: claude.ai에 올린 페이지(Artifact)로 열면, 보는 사람의 claude.ai 요금제로 Claude를 씁니다. API 키나 별도 결제가 필요 없고, 요금제 사용량에서 차감됩니다(처음 쓸 때 허락을 묻습니다).
  - 만들기: Claude 작성자 초안 → Claude 검토자가 원문과 대조해 검토(문제별 좋음/수정/교체) → 작성자가 의견을 따져 반영하거나 반영하지 않은 이유를 남기고 수정. 검토 0~2번, 생각 수준(빠르게/보통/꼼꼼하게) 선택.
  - 단답 채점, **질문하기**(자료를 근거로 Claude와 채팅), **문제 더 받기**.
  - 자료마다 **검토 기록** 탭에서 검토 의견과 반영 내용을 볼 수 있습니다.
- **기본 모드(무료, AI 없음)**: claude.ai 밖에서 파일로 열면 AI 기능이 숨겨지고 규칙으로 만듭니다.
  - 핵심어: 한국어 조사 떼기(광합성은·광합성이 → 광합성), 동사 거르기, 영어 단·복수 묶기와 두 단어 구, 여러 문장에 퍼진 정도로 점수
  - 정의 찾기: "~란 ~이다", "~을 말한다", "~을 …라고 한다", "X is a …", "X refers to …", 필기형 "용어: 설명"
  - 문제: 정의 객관식(설명→용어, 용어→설명), 빈칸(비슷한 생김새의 보기), 숫자·연도, 반대말·숫자·핵심어를 바꾼 OX와 정의를 바꾼 OX(O·X 번갈아), 단답. 문제 유형·난이도 설정을 따릅니다.
- **기본 제공 세트**: 처음 열면 보관함에 "알고리즘 6장 · 정렬"(문제 80개, 의사 코드 7개)과 "알고리즘 7장 · NP-완전 문제 (1~23쪽)"(문제 32개), "운영체제 7장 · 교착상태"(문제 33개), "운영체제 8장 · 메모리와 할당 (1~30쪽)"(문제 33개)가 들어 있습니다. 강의 자료 PDF의 글자와 그림(수행 과정·표·그래프)을 바탕으로 Claude가 직접 만든 요약·정리 노트·의사 코드·용어 카드·문제(의사 코드 빈칸 문제 포함)입니다. 지운 세트는 다시 들어가지 않고, 새 판(ver)이 나오면 풀이 기록을 유지한 채 내용만 바뀝니다.
- **그림 카드**: 앞면은 그림(배열 칸·힙 트리·결정 트리·목록·저장 장치 줄·흐름도·벤 다이어그램·자원할당 그래프·메모리 막대·표), 뒷면은 쉬운 설명·비유·꼭 기억할 것. 정렬 과정 같은 단계는 ◀ ▶로 넘기거나 자동 재생합니다. 기본 제공 세트에는 알고리즘 6장 11장·7장 7장, 운영체제 7장 9장·8장 11장이 있고(정렬 단계는 실제로 정렬을 돌려 계산), AI 모드는 Claude가 같은 형식으로 카드를 만들며, 기본 모드는 찾은 정의로 글 카드를 만듭니다. 코드: `cards.js`
- **카드에 내 그림 붙이기**: 카드마다 "그림 요청문 복사"(ChatGPT 등 이미지 생성 AI에 붙여 넣을 요청문)와 "내 그림 붙이기"(파일 선택·끌어다 놓기, 긴 변 1000px JPEG로 줄여 브라우저에 저장)가 있습니다. 저장 공간이 부족하면 다른 내용을 지우지 않고 알려 줍니다.
- **사용량 아끼기 모드(기본으로 켜짐)**: 생각 수준 "빠르게", 검토 없음, PDF 그림 쪽 전송 끔. 질문하기·채점·문제 더 받기도 고른 생각 수준을 따릅니다. 기본 제공 세트·그림 카드·용어 카드·오답 풀이는 Claude 사용량을 쓰지 않습니다.
- **의사 코드**: 요약에 의사 코드 패널이 있고, 문제 본문의 ``` 블록은 코드로 보여 줍니다. AI 모드는 자료의 의사 코드를 원문 그대로 옮기고 핵심 줄 빈칸 문제를 만들며, 기본 모드도 번호 붙은 의사 코드 줄을 찾아 반복 범위·비교 연산자·인덱스·대입 빈칸 문제를 만듭니다.
- **그림 쪽 읽기 (AI 모드)**: PDF의 그림·표가 있는 쪽(또는 글자가 거의 없는 쪽)을 골라 이미지로 바꿔 Claude에게 함께 보냅니다(한 번에 보낼 수 있는 이미지 수까지).
- 보관함·설정·대화는 이 브라우저의 localStorage에 저장됩니다.
- 파일: `index.html`, `style.css`, `sets.js`(기본 제공 세트), `cards.js`(그림 카드), `local.js`(기본 모드), `ai.js`(Claude 호출: 만들기·검토·채점·질문), `app.js`(화면)
