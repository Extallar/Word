# 편입영어 기출 단어장

한국공학대학교 편입영어 2022–2026학년도 기출 분석 엑셀을 바탕으로 만든 단어 공부 사이트입니다.

## 기능
- **단어장**: 파일에 나온 전체 단어 2,725개(5개년 어간 2,634개 + 3개년 표기형 중 누락 91개)와 우선 암기 어휘 217개. 출현 연도 수·학년도 필터, 검색, 뜻 가리기, 외운 단어 표시, 발음 듣기
- **카드**: 플래시카드 (영→한 / 한→영, 알아요·몰라요, 키보드 단축키)
- **퀴즈**: 4지선다 뜻 고르기, 틀린 단어는 오답노트에 자동 저장
- **기출 1~8번**: 2022–2026 동의어·어휘 빈칸 40문항을 실제 보기 그대로 풀기
- **문맥 빈칸**: 17~25번 27문항의 정답 표현과 판단 근거
- **풀이법**: 문법(9~16번)·독해(26~40번) 유형별 전략
- **오답노트**: 틀린 횟수 순으로 복습

학습 기록은 브라우저 localStorage에 저장됩니다.

## 실행
빌드 없이 `index.html`을 브라우저로 열면 됩니다. GitHub Pages로 배포하려면 저장소 설정 → Pages에서 이 브랜치의 루트를 지정하세요.

## 데이터 갱신
엑셀에 뜻이 없는 단어의 뜻은 `data/meanings/*.tsv`(단어<TAB>뜻)에 있습니다. 엑셀이 바뀌면 다음을 실행해 `data/words.js`를 다시 만듭니다.

```bash
pip install openpyxl
python3 tools/extract.py <엑셀파일.xlsx> data/words.js
```

`python3 tools/build_single.py`는 모든 파일을 한 장짜리 `dist/single.html`로 합칩니다.
